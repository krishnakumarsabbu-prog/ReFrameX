# ReframeX sample metadata

This folder simulates a small mainframe metadata set for testing the
artifact ingestion pipeline. Place the real 'M2O Hackathon Metadata'
folder elsewhere and set `M2O_METADATA_DIR` to its path.

Files included:
- `CLAIMCTL.cbl` — COBOL program (fixed record length 120)
- `POLICY.cpy` — Copybook
- `CLAIMJOB.jcl` — JCL job
- `LOAN_DDL.sql` — Db2 DDL + query
- `CLAIMMAP.bms` — BMS 3270 map
